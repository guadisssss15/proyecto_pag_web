## Objetivo del Sitio
El objetivo principal de este proyecto es transformar el desarrollo web escolar en un producto digital real, publicado y accesible desde Internet para toda la comunidad educativa de Arroyito, Córdoba. Busca ofrecer información clara, institucional y actualizada sobre la oferta educativa, admisiones, proyectos y vías de comunicación del colegio.

---

## Principales Secciones y Páginas
El sitio cuenta con una arquitectura multipágina estructurada de la siguiente manera:
* **Página Principal (`index.html`):** Portada de bienvenida institucional y accesos rápidos a las áreas del instituto.
* **Institucional (`NuestroColegio.html`):** Historia, valores y carisma de las Hermanas Mercedarias.
* **Oferta Educativa por Niveles:** Secciones específicas para Nivel Inicial (`NivelInicial.html`), Nivel Primario (`NivelPrimario.html`), Nivel Secundario (`NivelSecundario.html`) y Nivel Superior (`NivelTerciario.html`).
* **Áreas Institucionales:** Proyectos (`Proyectos.html`), Capacitaciones (`Capacitaciones.html`), Servicio de Orientación Escolar (`SOE.html`) y el Centro de Estudiantes (`CEM.html`).
* **Inscripciones y Contacto:** Formularios interactivos en línea conectados a bases de datos en la nube (Firebase) para admisiones, además de la página de Contacto (`Contacto.html`).

---

## Tecnologías Utilizadas
* **HTML5** para la estructura de las páginas web.
* **CSS3** (con hojas de estilo adaptables y `responsive.css`) para el diseño visual (*responsive design*).
* **JavaScript (Vanilla JS)** para la interactividad, gestión de datos dinámicos y carga de plantillas mediante archivos JSON.
* **Firebase (Firestore)** para la gestión y almacenamiento de los formularios de inscripción online.
* **Git y GitHub** para el control de versiones y versionado del código.
* **Vercel** para el servicio de *deployment* y alojamiento en la nube.

## Cómo Ejecutar el Sitio Localmente
Para probar y ejecutar el proyecto en tu computadora de manera local, seguí estos pasos:

1. **Clonar o descargar** el repositorio en tu equipo:
   ```bash
   git clone [https://github.com/tu-usuario/web-colegio-nombregrupo.git](https://github.com/tu-usuario/web-colegio-nombregrupo.git)
2. Abrir la carpeta del proyecto utilizando un editor de código como Visual Studio Code.
3. Instalar la extensión Live Server en Visual Studio Code (o utilizar cualquier servidor local compatible).
4. Hacer clic derecho sobre el archivo index.html y seleccionar "Open with Live Server" para visualizar el sitio web completo funcionando directamente en el navegador web.
